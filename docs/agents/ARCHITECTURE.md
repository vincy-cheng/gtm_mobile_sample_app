# Architecture

Flutter sample app demonstrating GTM (Google Tag Manager) + GA4 (Firebase Analytics) on Android and iOS.

## Entry point

`lib/main.dart` — single-file app. `main()` initializes Firebase (`Firebase.initializeApp` with `DefaultFirebaseOptions.currentPlatform` if no app exists yet), then runs `MyApp`.

## Data flow

- `MyApp` (stateless) creates a static `FirebaseAnalytics` instance and a `FirebaseAnalyticsObserver`, wired into `MaterialApp.navigatorObservers` for automatic screen tracking.
- `MyHomePage` (stateful) holds six buttons; each calls `widget.analytics.logEvent` / `setUserId` / `setUserProperty` and shows the result in `_message`.
- Events flow through the native Firebase/GTM SDKs to GA4. The GTM container decides per event whether to **add**, **modify** (rename), or **block** it — that logic lives in the GTM container config, not in Dart code. `test_adding_event`, `test_modify_event`, `test_block_event` exercise those container rules.

## Layout

| Path | Role |
| --- | --- |
| `lib/main.dart` | Entire app — init, widgets, analytics calls |
| `lib/firebase_options.dart` | Generated by flutterfire CLI; platform Firebase config (projectId `gtm-sample-app`) |
| `firebase.json` | flutterfire metadata mapping apps to config file outputs |
| `android/app/src/main/assets/containers/` | GTM container JSONs (Android) |
| `ios/container/` | GTM container JSON (iOS) |
| `ios/Podfile` | `pod 'GoogleTagManager', '~> 7.0'` (native iOS GTM SDK) |
| `android/app/build.gradle` | `play-services-tagmanager:18.1.1` (native Android GTM SDK) |

## Dependencies (pubspec.yaml)

`firebase_analytics ^12.4.3`, `firebase_core ^4.11.0`; dev: `flutter_test`, `flutter_lints ^5.0.0`. Dart SDK ≥ 3.2.3.

## Decisions

- GA custom event parameters support only strings and numbers — the `test_event` handler stringifies its bool (`'bool': true.toString()`) for that reason (comments in `lib/main.dart` cite the Firebase docs).
- GTM container JSONs are committed under platform-specific paths (see table above); `google-services.json` and `GoogleService-Info.plist` are **gitignored** — they contain API keys and are regenerated per developer via `flutterfire configure`.
- `test/widget_test.dart` is known-broken leftover scaffolding — details in [TESTING.md](TESTING.md).
