# Dev ops

Local developer workflow: setup, run, lint, test.

## Setup

1. `flutter pub get`
2. `firebase login` (requires Firebase CLI)
3. `dart pub global activate flutterfire_cli`
4. `flutterfire configure` — regenerates `android/app/google-services.json` and `ios/Runner/GoogleService-Info.plist` (both gitignored; may need manual download of the plist into `ios/Runner` per README)
5. GTM containers: place `GTM-XXXXXX.json` in `android/app/src/main/assets/containers/` and `ios/container/`

## Run

```bash
flutter run                # device/emulator required
```

## Verify

```bash
flutter analyze            # static analysis (flutter_lints)
flutter test               # widget tests — see TESTING.md: suite is red
```

`flutter analyze` reports ~268 issues; only 2 are in `lib/` code (`prefer_const_constructors_in_immutables` and `use_super_parameters` on `MyHomePage`'s constructor, `lib/main.dart:43`) — the rest are info-level lints from generated plugin sources under `build/macos/`. Expect that volume; don't treat it as a gate.

## Debug mode (seeing events in GA4 DebugView)

- iOS: Xcode scheme → Run → Arguments → add `-FIRAnalyticsDebugEnabled` and `-FIRDebugEnabled`
- Android: `adb shell setprop debug.firebase.analytics.app com.example.gtm_mobile_sample_app` (disable with the same command and `.none.` as the value)
